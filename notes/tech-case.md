# Technical case

Build something with the Proposales API and show how you think.

- Sign up free at proposales.com.
- Take the API key from the profile settings: https://secure.proposales.com/settings/profile
- Build anything useful, silly, or playful. A model, or the Vercel AI SDK, is a bonus.
- Host it on Vercel.
- Share the link.

Time spent is up to you. The thought process matters more than polish.
